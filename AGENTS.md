# Project Instructions & Deployment Protocol

## Deployment Target
- **Primary & Exclusive Platform**: **Vercel**
- **Repository**: `https://github.com/AayushMandavia/Vayne---Ecommerce.git` (`main` branch)
- **Configuration**: [`vercel.json`](./vercel.json)
- All future updates, bug fixes, asset additions, and releases for this store must target and deploy to **Vercel**.
- Netlify is deprecated and no longer used for this project.
